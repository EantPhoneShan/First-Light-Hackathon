# Credits and data sources

First Light is an independent student project for the NASA Space Apps Challenge 2026. It is not endorsed by NASA. No NASA logos, insignia or mission identifiers are used.

## NASA resources used (from the challenge Resources tab)

| Resource | How the game uses it |
|---|---|
| [Design and Develop Science Missions](https://www.nasa.gov/wp-content/uploads/2025/04/250323-design-and-develop-science-mission.pdf) | The four mission segments (launch, space, ground, user) structure the design screen and the team roles |
| [Concept Maturity Levels (CMLs), JPL](https://dataverse.jpl.nasa.gov/dataset.xhtml?persistentId=hdl:2014/44299) | Game stages follow CML 1 to 4: idea, feasibility, trade study, point design |
| [Mission Design Lab (MDL), Goddard](https://etd.gsfc.nasa.gov/capabilities/integrated-design-center/mission-design-lab/) | The team mode mirrors an MDL study: each discipline designs in parallel and reviews together |
| [CubeSat 101](https://www3.nasa.gov/sites/default/files/atoms/files/nasa_csli_cubesat_101_508.pdf) | Approximate part masses, power and data figures for small satellites |
| [A Learning Game About Telescopes](https://science.nasa.gov/mission/webb/game-build-it-yourself/) | Inspiration: science goals decide which instruments are allowed |
| [NASA Mission Viz](https://nasa.github.io/mission-viz/) | Reference for the orbit and simulation view |
| [General Mission Analysis Tool (GMAT)](https://software.nasa.gov/software/GSC-19468-1) | Reference for orbit concepts; the game uses simplified maths, not GMAT itself |

Numbers in the game are simplified and approximate, for learning only.

## AI use

AI tools were used to help write code, planning documents and text. AI-generated images, if any, are labelled as AI-generated in the game.
